# Creative Care Coaching

Creative Care Coaching (CCC) is an educational coaching center
for students from Class 6 to HSC.

## Target Users

- Students
- Parents/Guardians
- Teachers
- Coaching administrators

## Main Goals

- Present CCC professionally online
- Show courses and programs
- Show student achievements
- Provide class and course information
- Allow parents/students to contact CCC
- Build trust through results and educational content

## Brand Personality

- Professional
- Friendly
- Educational
- Modern
- Trustworthy
- Student-focused
